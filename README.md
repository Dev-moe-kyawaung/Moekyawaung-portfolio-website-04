## 🚀 Features

This portfolio website is a rich showcase of advanced development practices and a deep dive into the architect's professional journey and capabilities. Key features include:

*   **Interactive Design:** A smooth, animated user experience with custom cursors, scroll progress indicators, and engaging micro-interactions.
*   **Component-Driven Architecture:** Built using React, with well-organized components for each section of the portfolio (Hero, About, Apps, Architecture, etc.).
*   **Modern Styling:** Leverages Tailwind CSS for utility-first styling, ensuring a responsive and visually appealing design across all devices.
*   **Dynamic Content:** Utilizes TypeScript for type safety and maintains data for projects, timeline, testimonials, and tech stack in a centralized `data.ts` file.
*   **Performance Optimization:** Built with Vite for fast development builds and optimized production output.
*   **Code Snippets & Demos:** Integrates code examples and visual showcases (videos, images) to demonstrate technical proficiency.
*   **Detailed Case Studies:** Sections dedicated to Apps, Startups, Architecture, and Open Source contributions provide in-depth insights into project details and methodologies.
*   **Clear Navigation:** A sticky header with smooth scrolling to different sections of the portfolio.

## 🚀 Installation & Setup

To get this project up and running locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Dev-moe-kyawaung/Moekyawaung-portfolio-website-04.git
    cd Moekyawaung-portfolio-website-04
    ```

2.  **Install dependencies:**
    The project uses npm as its package manager. Install the necessary dependencies using the following command:
    ```bash
    npm install
    ```

3.  **Start the development server:**
    Run the following command to start the Vite development server:
    ```bash
    npm run dev
    ```
    This will launch the application locally, usually at `http://localhost:5173` (or another port if the default is occupied).
